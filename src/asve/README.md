# ASVE

Autonomous Scientific Verification Engine (ASVE) is a framework for
automated verification, analysis, and provenance tracking of scientific
software artifacts.

## Installation

Install ASVE:

```bash
pip install asve

```

## Development 

```
git clone https://github.com/ksaad20/ASVE-Autonomous-Scientific-Verification-Engine.git
cd ASVE-Autonomous-Scientific-Verification-Engine
pip install -e .

```

## Usage

```
from asve import verify

result = verify("path/to/project")

print(result)

```
